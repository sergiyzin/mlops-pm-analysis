# MLOps — Домашнє завдання №4

## Тема 9. Аналіз ML-експериментів

### Опис завдання

У цьому проєкті я проаналізував 5 ML-експериментів із класифікації квіток Iris. Основна мета — порівняти результати моделей, оцінити ризики та визначити готовність до staging/production.

### Які дані використали

- MLflow — параметри, accuracy, log loss та model artifacts.
- Prometheus — метрики `mlflow_accuracy` і `mlflow_loss`.
- Скриншоти експериментів із навчальних матеріалів.

### Обраний кандидат

**rf-depth3 (Random Forest)**

- Accuracy: 95,56%
- Log loss: 0,1415
- Model artifact: збережено

Ця модель показала найкращі результати серед п'яти експериментів.

### PM-рішення

**Need more experiments.**

На мою думку, модель є перспективною, але поки що недостатньо доказів для переходу в staging без додаткових перевірок.

### Основні ризики

- Невелика тестова вибірка.
- Непідтверджена повна відтворюваність.
- Відсутність підтвердженого rollback-плану.
- Немає повного плану production-моніторингу.

### Наступні кроки

Перевірити модель на додаткових даних, визначити критерії переходу в staging, підтвердити відтворюваність та підготувати план моніторингу й rollback.
